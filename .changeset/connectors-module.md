New subpath `eharness/connectors` (spec 24, ADR-0049..0052): connector definitions, connections (workspace or agent scope, stored as `ConfigProfile` rows of kind `connection` with OAuth credentials in a separate row), per-agent enablement with capability modes (`allow | ask | off`) and per-tool overrides, a server-driven setup flow engine with a closed view vocabulary (`startFlow`, `advanceFlow`, `completeOAuth`, stale-view guard, sealed scratch), OAuth 2.1 helpers (PKCE, RFC 9728 / 8414 discovery, dynamic client registration, code exchange, refresh under a lock, device grant), `activateConnectors` (stable plugin order, tool prefixes for several connections, permission rules with pinned asks that bypass mode cannot skip), `createConnectorService`, built-in connectors for the shipped plugins (`builtinConnectors`, `ensureBuiltinConnections`) and a custom remote MCP connector. `eharness/providers` gains the generic `SecretVault` (`webCryptoVault` with key rotation, `plaintextVault`) and `sealedProfileStore`. `eharness/mcp` gains `remoteMcpSource` (fresh bearer per request), `bearerAuthProvider` and `listRemoteMcpTools`. `eharness/testing` adds `connectionStoreConformance`, `credentialStoreConformance`, `enablementStoreConformance` and `flowStoreConformance`.
