Agent messaging in `eharness/subagent` (ADR-0038). New tool `send_message({ to, message })` (option `messaging`, default on for `'inline'` / `'policy'`; `messageToolName`, `messageLimits`): message `main`, an agent id, a child session id or a **name** (new optional `name` of the `agent` tool, `^[a-z0-9][a-z0-9-]{0,31}$`). A running agent gets the message at its next step as a framed `<agent-message …>` (`data-eh.input`, source `event`); a finished resumable agent is resumed on the same child session (same task id) and its report goes to the sender; a subagent can wake or steer `main`; user-stopped agents refuse. `SubagentDefinition.resumable` (default `true`) marks one-shot types, `subagentTasks.send(to, message, { from: 'user' })` lets apps message an agent as the user, `SubagentTask.name`, `data-subagent.run` gains `name` / `taskId`, `selfAgent` rebuilds names after a restart. Throttled (rate, duplicates, queue cap); a roster reminder lists addressable agents. Exports `AGENT_MESSAGE_INSTRUCTIONS`, `AGENT_NAME_PATTERN`, `AGENT_MESSAGE_MAX_CHARS`, `SEND_MESSAGE_TOOL`, `SubagentMessageLimits`. Set `messaging: false` to keep the tool set unchanged. `eharness/permissions` maps `send_message` to the `safe` tool kind.
