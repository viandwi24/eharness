Network defaults hardening (K-08). New Node-only subpath `eharness/web/node` with `nodeResolveHost` (a ready `resolveHost` for `webFetch`, `dns.lookup` with all addresses); `webFetch()` created without `resolveHost` (and without `onlyAllowed`) emits the new `W_WEB_NO_RESOLVER` warning once per session, and the web guide documents DNS rebinding and a pinned-IP `fetch` recipe. **BREAKING:** `openApiSource` responses are framed with `untrustedContent()` by default (`<untrusted-content source="openapi">`, like MCP text): a successful JSON response is now the compact JSON text inside the frame instead of the parsed value. Migration: pass `wrapUntrusted: false` to keep the parsed value. **BREAKING:** `eharness/http` accepts only `data:` URLs in client file parts by default (SSRF through server-side downloads); migration: `chat.allowFileUrls: true` (http/https) or a `(url: URL) => boolean` predicate. The provider catalog loader validates the shape per source (models.dev, OpenRouter), never overwrites a valid cache with an empty or invalid document, caps the body (`maxBytes`, default 16 MiB) and reports failures through the new `onWarning(message)` option; the client SSE parser drops lines over 1 MiB and events over 4 MiB of data.
