New subpaths `eharness/client` and `eharness/client/react` (spec 27, ADR-0059; Draft), the browser counterpart of `eharness/http`, lifted from the team example's web app. `createHarnessClient` is a typed `fetch` client of the routes (`HarnessHttpError` with `isAlreadyAnswered` / `isBusy` / `isDuplicate`); `createHarnessTransport` builds on AI SDK's `DefaultChatTransport` (last message only, `Idempotency-Key`, `202` as an empty stream plus `onQueued`, a duplicate of an active turn resumes it, replaying resume); `createChatSession` is the framework-neutral logic around a chat (history paging, follow a running turn with retry, steer while busy, stalled-connection check, interrupted-turn Continue/Retry, error wording) driving a `ChatBridge` that `@ai-sdk/svelte` `Chat` satisfies and `@ai-sdk/react` `useChat` satisfies through `chatBridgeOf`; `createActivityFeed` is an SSE reader with reconnect, `Last-Event-ID`, idle watchdog, health pings that detect a restarted server (boot id), polling fallback and dedupe; `createAttentionList` is an optimistic approvals inbox with a generation guard, generic over the item (`AttentionList<Item, Answer>`), with a `list` source (an app's enriched view instead of `GET /attention`), `events` (the activity types that refetch; `ATTENTION_EVENTS` is the default) and app-defined answer kinds (`parseAnswer`) without casts; `followSessionStream(client, sessionId, { signal, onMessage, onChunk, onError })` is a read-only follower of the active turn of a session this tab did not start (AI SDK transport and `readUIMessageStream`). `headers` may be a function returning a record with `undefined` values (dropped); every JSON call takes `init` (`cache`, `keepalive`, ...) and `health()` is always `cache: 'no-store'`. Stores follow the Svelte store contract and work with `useSyncExternalStore`. `eharness/client/react` takes React by injection (`createReactBindings(React)`), no peer dependency. The client imports only `ai` at runtime; `check:imports` and a post-build check (`scripts/check-client-bundle.ts`, part of `check:package`) enforce it.
