New subpath `eharness/http` (spec 26, ADR-0059; Draft), lifted from the team example: `createHarnessHttp(agent, { authorize, ... })` returns a `fetch(Request): Promise<Response>` handler (Web APIs only) with the routes every harness server rewrites. **Chat** (`POST /sessions/:id/chat`: a `useChat` endpoint on `handleChatRequest` with a strict body whitelist, idempotency by message id or `Idempotency-Key`, stale-answer `409`, busy policies `reject` / `wait` / `steer` with `202` for a turn of another instance and `409 EH_SESSION_BUSY` for a turn on another instance with `ifBusy=reject`, respond, regenerate and edit; `GET /sessions/:id/chat/stream` resume; `POST /sessions/:id/interrupt`), **sessions** (snapshot, paged messages, optional list), the **attention** queue (`GET /attention`, `POST /attention/:id/answer` with ownership checks), and the **activity** feed (SSE and paged, filtered per principal). One required `authorize` hook runs before any body is read or session opened; every error has the shape `{ error: { code, message, details? } }` with a documented status table.

Hooks: `chat.validate` (after the body was sanitised; may deny or return a normalised `{ body }`), `attention.decorate` (adds `item.extra` to `GET /attention`, `null` hides an item; wire type `AttentionItemWire`), `attention.parseAnswer` (receives `defaultParse()`, may return `undefined` to fall back to the whitelist: `maxNoteChars`, `allowRemember`), `attention.agentId` (a string or a function of the session id) and `attention.onSettled` (runs when the continuation of a `resumed` answer ends).

Also exports the wire types, `sanitizeChatBody`, `httpError` and `openAccess` (development only), and `httpConformance` in `eharness/testing`. Bun closes a connection after 10 s without bytes by default: set `idleTimeout: 0` on `Bun.serve` for chat streams (see the HTTP guide).
