Permission engine and sandbox hardening (K-09). **BREAKING:** `AutoVerdict.decision` gains `'ask'` (a classifier that returns it hands the action to a person; custom classifiers need no change). **BREAKING:** the approval guard's verdict cache now expires after 1 hour by default (`cache.ttlMs`, `Infinity` restores the old behaviour); an input longer than `transcript.maxChars` is no longer judged (it asks a person), and `modelClassifier` asks instead of judging an action over 2000/4000 characters (migration: raise `transcript.maxChars`). **BREAKING:** a session grant or suggested rule never covers a high-risk flag (`--force`, `git push -f`, `--privileged`, `-v /…`, `--mount`, `rm -r/-f`, `--hard`…): such commands ask again; an allow rule with a wildcard no longer approves `python -c` / `node -e` / `perl -e` style inline code (only an exact rule does). New engine option `realpath` (with `nodeRealpath` from `eharness/filesystem/node`): protected paths and Read/Edit rules also match the symlink-resolved path (`g -> .git`, `x -> .env`). Deny rules now see through `xargs [flags]`, `find -exec`, `busybox`, `setsid` and `flock`. The bubblewrap sandbox adds `--unshare-pid --unshare-ipc --new-session`. `diskFs` opens files with `O_NOFOLLOW` and re-checks containment after the open; `nodeCheckpointStore` rejects traversal session ids (`..`).
